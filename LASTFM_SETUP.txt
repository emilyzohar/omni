LAST.FM MUSIC DISCOVERY SETUP

Recommended for Vite projects:
VITE_LASTFM_API_KEY=YOUR_LASTFM_API_KEY

Also supported for projects whose Vite config exposes the EXPO_PUBLIC_ prefix:
EXPO_PUBLIC_LASTFM_API_KEY=YOUR_LASTFM_API_KEY

Compatibility aliases also accepted:
VITE_LASTFM_KEY
EXPO_PUBLIC_LASTFM_KEY

IMPORTANT
- Restart the Vite dev server after changing .env files.
- For a deployed/production app, rebuild and redeploy after adding/changing the key. Vite injects client environment values at build time.
- You only need the Last.fm API key. The shared secret is not used for these read-only recommendation endpoints.
- The browser console logs whether Last.fm was detected and the env variable NAME used, but never the key value.

Expected console output after a correct build:
[Config] API availability { lastFmConfigured: true, lastFmEnvName: 'VITE_LASTFM_API_KEY', ... }
[Discover][Music] music collector start { ..., lastFmConfigured: true, ... }
[Last.fm API] request ...

If lastFmConfigured is false, the key was not exposed to the client build. Check the env name and rebuild/restart.
